# onecoinstududios-official.github.io

Official One Coin Studios website. Plain HTML/CSS — no build step, no JS.
GitHub Pages serves the `main` branch root at
<https://onecoinstudios-official.github.io/>.

## Languages

`en` (root, master) · `de` · `es` · `ja` · `pt-br` · `ru`

Page copy comes from the store listings in
`games/bento_blitz/store/listings/` — those are the single source of truth.
If a listing changes, mirror it here (title + short description per page).

## Files

- `index.html` + `<lang>/index.html` — one page per language
- `style.css` — shared styles (tokens match `policies/bento-blitz.html`)
- `assets/` — logo, favicon, OG banner (1200×630), game sprites
